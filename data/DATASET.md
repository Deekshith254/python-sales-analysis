# Data source — institute assignment

**Official dataset:** [vinothkannaece/sales-dataset on Kaggle](https://www.kaggle.com/datasets/vinothkannaece/sales-dataset)

Download **`sales_data.csv`** from Kaggle and place it in this folder (replace the bundled copy if you use the official file).

**Columns:** `Product_ID`, `Sale_Date`, `Sales_Rep`, `Region`, `Sales_Amount`, `Quantity_Sold`, `Product_Category`, `Unit_Cost`, `Unit_Price`, `Customer_Type`, `Discount`, `Payment_Method`, `Sales_Channel`, `Region_and_Sales_Rep`

The notebook `Sales_Analysis_Python.ipynb` loads `sales_data.csv` and covers **Part B & Part C** of the graded assignment (tasks 5–12).

See `INSTITUTE_ASSIGNMENT.md` for the full Part A / B / C checklist.
