# Sales data — Python (Pandas & charts)

**Author:** Salimeda Deekshith  

Data analysis project using **Pandas** and **Matplotlib** on a sales dataset (Cloud Vision Technologies — Data Analytics with AI).

**Dataset:** [Kaggle — sales-dataset](https://www.kaggle.com/datasets/vinothkannaece/sales-dataset)  
**Related repo (Excel part):** [sales-data-analysis](https://github.com/Deekshith254/sales-data-analysis)

---

## How to run

1. Install **Python 3.11+** and run:
   ```powershell
   python -m pip install -r requirements.txt
   ```
2. Place **`sales_data.csv`** in the **`data/`** folder (download from Kaggle — see `data/DATASET.md`).
3. Open the notebook:
   ```powershell
   jupyter notebook Sales_Analysis_Python.ipynb
   ```
4. **Kernel → Restart & Run All**, then save the notebook.

## Outputs

| Output | How it is produced |
|--------|---------------------|
| Pandas tables & statistics (tasks 5–8) | Printed in the notebook after you run it |
| Matplotlib charts (tasks 9–12) | Displayed in the notebook; optional: save figures to **`output/`** |
| Submission artifact | **`Sales_Analysis_Python.ipynb`** with outputs saved |
